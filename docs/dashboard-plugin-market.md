# 用户插件市场

用户在工作台的“智能体 → 插件市场”（`/plugins`）浏览同一份插件目录。每个用户独立安装、启用、配置和卸载。首个插件为 DeepSeek & Go，界面参考 [dsh-cost-meter](https://github.com/Han-1413141/dsh-cost-meter)。已有的服务器工具插件管理继续位于 `/admin/plugins`，由原有 `plugins` 权限控制。

## 使用

1. 打开插件市场，安装 DeepSeek & Go。
2. 无需密钥即可查看 DeepSeek 峰谷状态、北京时间的全天时段条和下一次切换倒计时。周末与中国公众假期全天低谷。
3. 在“配置”中填入自己已订阅工作区的 OpenCode Go API Key。支持粘贴带 `Bearer ` 前缀的值。留空保留现有密钥，可以单独清除。
4. Go 采用官方的滚动 5 小时、周、月三个周期，不将 5 小时额度标成日额度。每个周期显示已用百分比和官方提供的重置时间。默认每分钟查询，服务端按账号限制最短刷新间隔。
5. Go 的额度接口没有订阅到期字段，因此到期时间由用户按控制台填写，并显示“手动设置”。月额度重置日不会充当订阅到期日。
6. 安装后可在聊天输入框下方显示迷你条，点击展开完整看板。可关闭聊天显示或停用整个插件。

## 数据与权限

目录由 `infra/plugins/marketplace.py` 的受信任注册表提供；普通用户不能上传或运行服务器代码。新增原生看板插件需要登记目录元数据，并实现对应前端组件与服务端接口。

安装记录、配置、额度快照共同保存在既有 `settings` 表的一个账号插件记录中，键为 `dashboard_plugins.user.<已认证用户 ID>.<插件 ID>.state`。更新使用数据库原子的比较后写入，卸载删除整个记录，迟到的保存或额度查询不能恢复已删除的密钥。接口不接受目标用户 ID，每次只从认证上下文获取账号。服务端适配 SQLite 与 PostgreSQL 的既有 KV 仓储，无需迁移。

密钥使用现有 Fernet 凭据组件加密后保存。响应仅包含 `key_configured`，从不返回密钥。浏览器不保存 API Key。配额请求只发送到固定 HTTPS 地址 `https://opencode.ai/zen/go/v1/usage`，禁止跟随重定向，不读取宿主机环境变量或 CLI 登录态。错误响应不透传上游正文，防止上游回显密钥。

未配置、查询失败、数据缺失、数值无效和实际 0% 分别处理。查询失败保留最后一次成功快照并提示过期数据。重置时间到达后等待新的官方数据，不在本地把已用额度直接归零。切换账号后立即隐藏旧账号快照，并丢弃迟到的旧响应。

卸载只清除当前用户的安装记录、设置和快照。停用保留配置并停止向 Go 发出额度请求。

## 接口

所有接口要求登录；个人数据响应使用 `Cache-Control: no-store`。

| 方法 | 路径 | 行为 |
| --- | --- | --- |
| GET | `/api/plugins/catalog` | 共享目录与当前用户的安装状态 |
| PUT | `/api/plugins/mine/{plugin_id}` | 当前用户安装或修改启用、聊天显示开关 |
| DELETE | `/api/plugins/mine/{plugin_id}` | 清除当前用户的插件及配置 |
| GET | `/api/plugins/cost-meter/state` | 峰谷状态及自己的缓存配额，不发起上游查询 |
| PATCH | `/api/plugins/cost-meter/config` | 保存或清除密钥，设置带时区的订阅到期时间 |
| POST | `/api/plugins/cost-meter/refresh` | 使用当前用户的密钥刷新额度 |

## 时间规则和维护

峰时段为北京时间工作日 09:00 至 12:00、14:00 至 18:00，区间含起点、不含终点。使用北京日期判断周末，调休上班的周六、周日也为低谷。当前附带[国务院公布的 2026 年公众假期表](https://www.beijing.gov.cn/fuwu/bmfw/sy/jrts/202511/t20251104_4258838.html)；未收录的年份会在界面明确提示仅按工作日和周末计算，维护者应随官方假期通知更新表与相应测试。

时段条固定标注北京时间。配额重置、更新时间和用户填写的到期时间遵守 Octopus 的服务器时区。倒计时使用服务端时间校准，避免浏览器时钟偏差。

## 验证

专项验证包括峰谷边界、周末及节假日、跨账号安装和密钥隔离、加密存储、空密钥保留、独立冷却、停用停止查询、错误回显脱敏，以及空值不会误报为 0%。前端覆盖路由权限、普通用户导航和切换账号时丢弃旧请求。浏览器实测使用隔离的本地账号，不依赖生产环境密钥。
