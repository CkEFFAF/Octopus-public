Revision: 2026-10-18.1

The user explicitly requested public conversation URLs, link management with closure, Agent Native support, an updated OpenCode Go catalog and cloud/execution-client deployment. We keep existing FastAPI, SQLite/PostgreSQL, React and the current management-tool authority boundary.

A frozen filtered snapshot makes publication scope reviewable. A live private-thread view would expose later messages and couple anonymous reads to private runtime authority. Token hashing plus standard encrypted recovery supports both public capability lookup and owner recopy without storing plaintext tokens. Revocation is checked on reads and observed by the public page's bounded revalidation; it cannot erase a recipient's existing copy.

Preview digest validation prevents publishing messages that arrived after the owner's preview. Strict text projection and a separate public renderer avoid private media credentials, thinking, tool execution or remote-image tracking. A trusted configured public origin is required because an agent has no browser origin and bind/forwarded/SSO URLs are not a sound publication authority.

The local Go bundle already includes the requested MiMo models, while configured provider models are stored separately. Updating only the template or only a configuration modal would leave existing runtime selection stale. A central additive effective catalog exposes new options while honoring explicit persisted overrides and keeping the scheduled experiment's selected model unchanged. Protocol-specific official endpoints matter; Google-only entries cannot be advertised through an OpenAI fallback.

User authorization covers deployment in this task. The current GPU-manager cron and live experiments require a staged idle-window rollout and identity-preserving client updates. Actual paths, current scheduler state, package hashes and functional smoke checks are stronger evidence than old operation notes or the unchanged b16 version label. No public release or Git publication is necessary to perform this authorized private rollout.
