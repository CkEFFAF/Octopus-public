## Goal

网页对话在用户**未真正 opt-out**时，自动继承 **设备包 ∪ 专家** MCP 默认（冷启动时仍含账号 `default_open`）；保留 `mcp_servers: []` 作为**显式清空**。

用户确认：「改」。

---

## Problem

Dashboard 几乎总是带上 `metadata.mcp_servers`（含冷启动 `[]`）→ 后端 `apply_defaults=False` → 账号 / 设备 / 专家默认**全部跳过**。IM 缺 key 则正常继承。此为 0025 DEC-C06 与 FE「始终传数组」叠加的副作用。

另：即便 FE 传非空勾选，今日也会跳过设备包（composer 不含设备 MCP 名）。

---

## DEC（拍板）

| ID | 决议 |
| --- | --- |
| **DEC-C06′**（修订） | **三态**：(1) **缺 key** → `apply_defaults=True`：账号 `default_open` ∪ 专家 ∪ 设备包；(2) **`[]`** → 真 opt-out：三层都不注入；(3) **非空 list** → `explicit ∪ 专家 ∪ 设备包`，**不含**账号 `default_open`（用户已在组名单，避免再灌全账号默认）。 |
| **DEC-C13** | **前端最小修复（主路径）**：冷启动 / 未清空连接器时 **不要发送** `mcp_servers` key（`undefined`/省略）；仅在用户清空连接器、或 ask/plan / team 限制模式时发送 `[]`。 |
| **DEC-C14** | **后端加固（同 PR）**：即使收到非空 `mcp_servers`，合并时仍并入专家 `extra_defaults` 与设备包；仅 `[]` 或显式 opt-out 跳过 scoped defaults。账号 `default_open` 仍仅在缺 key（或未来 mode=defaults）时注入。 |
| **DEC-C15** | **不采用**单独把 `[]` 解释成「仍注入设备+专家」——会破坏真 opt-out。不强制本 PR 上 `mcp_servers_mode` sentinel（可列为 follow-up）。 |

## 实现要点（Coder）

### Frontend（优先）

| 文件 | 改动 |
| --- | --- |
| `dashboard/src/pages/Chat/hooks/useChatSend.ts` | `connectors.length===0` 且非 restricted(ask/plan) 且非「用户已清空」→ 传 `mcpServers: undefined`；restricted / 用户清空 → `[]` |
| `dashboard/src/pages/Chat/hooks/chatStore.ts` | 保持「仅当 mcpServers≠null/undefined 才写入 payload」；确认 `undefined` 不写 key |
| `useChatComposerResources` / `resolveInitialConnectors` | 区分「初始空」与「用户点清空」；清空置 opt-out 标记 |
| 测试 | `useChatComposerResources.test` / send 路径：冷启动不带 key；清空带 `[]`；ask/plan 带 `[]` |

### Backend

| 文件 | 改动 |
| --- | --- |
| `gateway/process/processor.py` `_resolve_turn_mcp_servers` | 非空 explicit：仍加载 expert + device pack；`[]`：返回空/None；缺 key：现逻辑 |
| `connectors/service.py` `merge_turn_mcp_servers` / `default_open.py` | 拆「account defaults」与「scoped defaults（expert+device）」；`apply_defaults=False` 时仍可 `apply_scoped=True` |
| 测试 | 矩阵：missing / `[]` / `[x]` × 有无设备包 × 有无专家名单 × default_open |

### 不做

- 不改 team host 无 MCP（0028 invariant）。
- 不批量改专家 `mcp_servers`。
- 不引入完整 mode 枚举（除非同 PR 极小且测全）。

| **AC-D05** | Given IM 缺 key；When 发回合；Then 行为与改前一致（全 defaults）。 |
| **AC-D06** | Given team host；When 任意；Then 仍无 MCP。 |
