# 对话页面信息层级调整

Status: In Progress (2026-10-09)

Revision: 2026-10-10 — 用户要求桌面常用工具直接可见，并修复设备与用量重叠。

## Summary

保留 Octop 的三段式导航、现有群聊/私聊、消息与工具能力，只收紧对话页的
信息层级。用户应先看见会话与回答，再按需展开思考、设备和高级工具。

## Requirements

- AC-1：桌面会话栏按群聊/私聊分组，当前智能体与会话使用平坦列表；名称可见，
  描述不占常驻行，选中态清晰。搜索、新建、隐藏/恢复与会话菜单仍可操作。
- AC-2：单聊和群聊的思考/工具过程默认折叠，运行中显示状态摘要；用户能手动
  展开，原有本地偏好及键盘操作保留。回答正文不被思考块挤出首屏。
- AC-3：设备选择与会话用量放在输入框上方可换行的上下文栏；选择器、管理入口
  与用量互不重叠，长用量可换行。没有设备时不显示空选择器；已有选择和离线
  状态保留，手机仍能管理设备。
- AC-4：宽桌面输入区直接显示模式、模型、专家、连接器、技能、子智能体和快捷
  指令的可用入口；窄栏和手机才使用「更多工具」收纳。复用原选择面板与能力
  可用性，不将不可用选项硬加到群聊。附件、发送和提及始终可用，润色仅在
  有文本时出现。工具区可换行而发送区不被挤出。
- AC-5：桌面窄列和手机无水平溢出；按钮均有可读名称；消息发送、群聊提及、
  附件和模式/模型/连接器/技能选择行为不变。

## Decision / Design

延续现有 React、Ant Design 与 LESS，不换聊天数据模型或消息协议。会话列表
保留现有组件和分组逻辑，移除当前智能体的外层色块与常驻描述。工具菜单复用
已有 picker/flyout；按输入区实际宽度展示直接入口或收纳菜单。设备组件保持
挂载，只在零设备时不渲染其行，避免丢失选择状态；上下文栏不用覆盖定位。
思考仍可在标题菜单改为自动展开，默认值改为折叠。

## Build plan

1. 调整 SessionList 与侧栏样式，验证群聊/私聊和会话菜单（AC-1、AC-5）。
2. 改思考默认值及相关测试，验证流式/历史/手动展开（AC-2）。
3. 修正上下文栏的收缩与换行，宽桌面恢复直接工具入口（AC-3、AC-4）。
4. 跑受影响前端测试、类型检查、构建；在本地页面检查桌面和手机宽度（AC-5）。

## Consequences / Follow-up

首轮只改变呈现与入口位置，不改设备权限或 Agent 执行。用户现有本地思考偏好
继续生效；已有显式选择“展开”的用户不会被强制覆盖。原生 Linux/手机真机
仍需单独验收。
