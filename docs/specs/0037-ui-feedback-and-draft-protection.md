# 0037 — 原有风格下的 UI 反馈与编辑保护

Status: In Progress

用户要求继续优化，最后合并部署；明确保留原有视觉风格。实施基线为 `origin/main` 的 `bc426e45`，从该提交建立独立 hotfix，避免夹带未合并的模型目录开发。

## 验收

1. 原有品牌、默认色板、全局布局和个性化主题保持；手机导航不超出 320px，选择个人设置后收起。
2. 历史消息中的明确模型失败封装可恢复为错误卡，沿用主分支的本地化和安全诊断；普通回答提到错误标记仍是正常回答。
3. 项目、看板初次加载与读取失败不伪装为空数据；项目空状态能创建关联任务。任务列表示阶段，最近执行状态只来自 `runs`，操作错误不被轮询清除。
4. 项目/任务表单有修改时，关闭表单需确认，继续编辑保留内容；浏览器刷新/关闭标签页由原生提示保护。AI 拆解输入同样计为修改；保存期间不重复提交。此批不承诺 SPA 全局切页草稿恢复。
5. 模型可按名称、ID、服务商搜索；同名模型显示 ID；明确区分启用和本次测试结果，未点击测试不得调用模型。无匹配可清空搜索，操作按钮有可访问名称。
6. 看板无匹配与无任务区分，可清除搜索、标签和成员筛选，保留当前项目。更换项目不丢弃其他 URL 参数。
7. 更新页面前确认影响，服务模式读取/重启失败时显示错误且不继续刷新。本批不增加持久健康监控或假设能检测所有用户的后台任务。
8. 运行真实本地应用及定向/全量检查；检查最终 PR 当前提交，合并后使用该树构建部署包。部署前检查任务空闲、备份并保留旧安装，部署后核验公网静态资源与健康。

## 边界

无新增后端能力、数据库迁移、模型自动调用、账号授权变化或设备重装。不采用早期三套视觉原型；未合并的模型目录 PR 不在本批发布范围内。跨项目成果聚合、全站草稿恢复、全部远控与实体手机键盘验收另行推进。
