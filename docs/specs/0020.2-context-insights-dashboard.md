## Goal

1. **面 A**：把会话内 Context 升到与 dsh Context tab **同级信息密度与 IA**（Stats 行 + Token/Timing donut + Current + Trend + Browser 多小块网格）。窄 Chat dock 不够时 **可展宽 dock / 会话内全宽 Context 子页或抽屉**——**禁止**继续只改 Segmented/排序交差。
2. **面 B**：WorkspaceNav **一级 Insights 全页**（跨会话 KPI + 时间范围 + Sessions 可搜列表；图区按数据诚实分期）。
3. 两面 **共用** 只读 `context_insights` 聚合层；与未来 `context.insights` tool 同口径。

## Non-goals

- 不平行新造第二套 usage/KPI / 第二套 Context 面板品牌。
- 不碰 `work_mode` / 证据校验 / receipt 记账语义。
- 不伪造余额 / 精确计价（无 SoT → `—` / `gaps`）。
- MVP **不**实现 Stats 关系图、Agent Network 成本网、跨会话 heatmap/精确 Cost（标 P1）。
- MVP 不强制注册 `context.insights` tool（service 方法可先就绪）。
- 0020.1b 已定 pills/多小块/回执规则 **不回滚**；本规格是密度与展宽，不是重做排序。
