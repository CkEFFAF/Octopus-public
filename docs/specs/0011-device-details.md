# 0011 设备卡片与详情

- Status: Implemented
- Date: 2026-10-12
- Baseline: `0004-same-account-auto-enroll.md` 的同账号自动登记与现有设备权限模型

## Outcome

设备客户端登录同一 Octop 账号后，管理页自动列出该账号的设备。每张设备卡片提供刷新、重命名、查看详情和撤销设备操作；无需为查看或改名进入远控工作区。

## Acceptance

1. 已登记设备的卡片菜单可打开重命名，保存后列表显示新名称；空白名称不可提交。重命名只调用当前账号已有的设备更新接口，不修改设备身份或授权。
2. 详情显示登记名称、平台、设备 ID、连接状态、最近在线时间、能力、授权权限和共享目录。设备离线时仍可查看这些登记信息。
3. 在线时详情按需请求 `status`，展示客户端报告的主机名、系统版本、架构、处理器和主板；未报告的字段明确标注。离线或请求失败时不冒充实时信息。
4. 常规心跳 `ping` 不收集硬件详情。设备详情请求继续受现有账号归属校验约束。
5. “添加设备”以同账号登录自动登记为主路径，一次性配对码保留为备用路径。

## Scope boundary

不改变自动登记、密钥、设备权限或桌面控制协议；不采集序列号、网卡 MAC、进程列表或其他机器识别数据。撤销操作继续使用现有接口与确认提示。
