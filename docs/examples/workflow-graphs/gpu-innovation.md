# GPU 实验的两张流程图

原来的32节点技术图已被两张业务图替代。底层身份、版本、设计和代码哈希校验留在确定性脚本中，不在画布铺开。

## 设计与审阅，5个节点

开始设计 → 预先设计实验 → 高级模型审阅设计 → 冻结设计并入队 → 查看设计队列。

它不要求GPU空闲。先读原始准则、领域知识、数据先验和唯一任务事实源 `OCRL-3DSSG-Codes/agent/TASK_QUEUE.md`，为已认可backlog提前写带T编号和设计版本的文档，再由独立会话审阅。方案必须具体到真实代码文件、接口、数据流和分步实践及验证，不能只写代号或一句假设。未决前置、终止/否决和不符合共享GPU规矩的项目不可批准。空批次安全结束，不新增实验。

设计模板为 `gpu-experiment-design-template.md`，审阅模板为 `gpu-experiment-review-template.json`。每条队列保存 design_path、design_revision、design_review_path。设计、评审和真实调用证据在批准时冻结SHA256；领取和运行前再次核对。任何变化需要新版本和复审。真实Graph review wrapper从引擎提供delivery_id/thread_id，登记脚本保存原始证据；文件哈希本身不能证明任意调用者声称的模型身份。

设计稿可由Codex预先补齐并保持pending。没有正式审阅、未冻结配置/基线/命令或仍有科学阻塞的草案，不等于可执行任务。原表中的任务状态和用户原有准则保持优先。

## 执行与报告，9个节点

开始执行 → 检查资源并领取 → 有就绪任务？ → 按设计实现 → 高级模型核对实现 → 等待空闲并运行 → 分析与实验报告 → 校验并归档 → 查看结果。

唯一显式分支是没有就绪候选或资源忙时结束本轮。DeepSeek只按固定设计实现，不能现场发明另一套科学方案，也不能启动训练。它输出实际文件与SHA256清单；高级模型独立核对，run_prepared再校验原claim、设计版本、代码清单和真实review wrapper。准备或复核拒绝会产生真实接纳拒绝回执，交分析归档；没有训练时不编造退出码或指标。

运行前资源临时丢失时，同一个持久设备Job每60秒重查同一领取，等待期间不调用模型、不持有数据库写锁。不会反复提交已受理的训练。GPU0必须满足当前保守空闲检查，不会杀、清理或抢占别人的进程。检查和其他用户恰好同时启动之间没有硬件级原子预留，不能宣称绝对没有外部竞争。

run_prepared是编排使用的入口。旧run保留为管理员兼容入口，不包含新的代码审阅封装；专家流程不得直接用它跳过实现复核。确定Popen未启动的OSError会记录真实错误、process_started=false和returncode=null；实际启动后的中断或无法核实的副作用保留running/unknown，禁止自动重投。

archive只按实际账本状态选择finish、report_failure或准备失败的fail，不接受模型自选成功。报告和真实证据不齐时返回manual_review并保留状态。exit 0、报告归档和科研指标改善是三个不同结果；候选/基线必须同protocol，完整报告保留不利指标。下一创新版本先回设计与审阅，不能直接临时改代码跑。

## 调度与预算

正常配置使用每30分钟调度及overlap=skip，每次执行实例只处理一个版本。Grok 4.7是原定高级设计/审阅/分析模型，DeepSeek用于实现。ACP是高级节点的可选执行方式，不复制成另一条平行线路；必须有真实调用与回执，不可用就明确失败。

当前所有者暂停Grok测试，OpenCode Go五小时额度已用完。线上验收配置仅保留DeepSeek模型选择，两张图的自动调度与实际训练均关闭，设计登记不给自动批准scope。离线模拟不代表真实模型回合或高级审阅成功。额度恢复及所有者恢复授权前不自动重试该服务商。

## 关键文件和会话

`agent/designs/DESIGNS.md`显示预先设计草案及阻塞；`gpu-innovation/DESIGNS.md`是已进入正式登记流程的设计审阅索引。QUEUE.md、STATUS.md、REPORTS.md分别显示执行账本、当前进度和版本报告链接；它们都不能覆盖原TASK_QUEUE事实。

置顶文件跨会话共享。右上角“删除”进入选择模式，勾选并确认后只移除置顶入口，不删除源文件。

本地Agent与专家、专家与ACP的交互归入“Agent协作”会话，来源由服务端机器凭据和真实ACP会话确定。Codex使用独立oaa_机器身份和现有work-items入口，不换用户JWT冒充所有者；ACP单独保留双方身份、实际记录和父会话链接。额度限制下尚未完成的专家沟通不能记成已确认。
