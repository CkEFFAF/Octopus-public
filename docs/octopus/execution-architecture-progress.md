### Implemented and verified in source

- Explicit LocalExecutionBackend is implemented end to end: persisted `target_kind=local` with no device ID, admin/account validation on every operation, account/expert/session defaults, request-scoped tools/ACP, and frozen workbench targets. An empty device target still means unselected. The local UI exposes the option without selecting it automatically; preview device permissions were not changed.
- Native context-bound file transfers now use 1 MiB chunks, incremental SHA256, destination concurrency checks, cancellation/idle cleanup and temporary-file identity recovery. Upload/download and cross-device copy operate on native paths; no shared root is required in owner mode. Browser downloads use a streaming file writer where available and a truthful 256 MiB Blob fallback limit otherwise. Uploads are bounded at 64 GiB. Full device-service/executor transfer regression preserves binary content outside cwd and rejects a different context.
- Controller Job reconciliation runs every 15 seconds, at most four observations in parallel and 64 due receipts per tick. It reauthorizes the original context, survives observer recreation, does not replay commands and records unavailable observations separately from the last real status. Reopened workbenches retain the original Job/Run association. Loss of local host admin authority stops that account's active Jobs and interactive runtimes. CPU/RSS observations include optional NVIDIA per-process memory, with a five-second collector cache and explicit unavailable/unknown values. The actual SSG3090 collector reports available; the empty PID filter returned no unrelated process observations.
- Fixed the SDK synchronous SQLite close race: the owning worker now closes its handle and is joined before event-loop shutdown. A new worker-lifecycle assertion reproduced the old failure. Fixed Windows Job state read/atomic-replace collisions with a bounded retry for the actual transient lock errors; persistent denial still fails, original state remains intact. The attempted shared-delete handle approach was rejected by its regression and removed.
- Owner policy v3, desired/applied receipts, immutable request contexts, account/expert/session target precedence and explicit unavailable-target handling. No first-device or host fallback. Native OS paths and normal OS links work outside the default directory; account ownership and current policy still apply.
- SDK AgentStore/project backend separation, native graph tools, context-scoped ACP, authenticated peer target inheritance, persistent modes and receipt-backed workflow evidence. Independently reported WorkMode, browser context, snapshot and shutdown defects have fixes and regression evidence. The final incremental independent recheck was interrupted by reviewer usage limits and is not reported as clean.
- Device file editor, Git/diff/recovery, persistent Jobs, Windows ConPTY/POSIX PTY and device-local browser/localhost previews use frozen contexts. Browser lanes are generated from authenticated account/expert/thread identity; cookies stay on device. Inputs have backpressure and uncertain outcomes are never automatically replayed. Idle browser contexts now close without requiring another request.
- Selected-device Skill/CLI/MCP discovery and Skill inspection/import share the execution catalog. CLI authentication and MCP connectivity are explicitly unverified; discovery is not a claim that those integrations were executed.
- Final-provider RequestSnapshots, durable RunEvents, honest usage/cache/unknown statistics, component comparisons and actual compression receipts. SDK automatic summarization uses a public middleware extension; a reused old summary does not generate a new compression event. Manual compaction emits its real before/after message estimates. These estimates cover messages, not system/tool tokens.
- Request source attribution now partitions actual provider-bound content into reference files, Skill catalog entries, pinned Skill bodies, memory recall and conversation summaries, retaining source paths without counting the same text twice. File tool results correlate with their actual preceding read call. Ordinary text mentioning a Skill is not classified as imported Skill content. A real DeepAgent graph regression covers the injection boundaries.
- Desktop I/O now runs on one native worker thread, keeping mss creation/capture/close together and leaving connection heartbeats responsive. Lowercase UI keys and chords are normalized; all held modifiers are released on failure. Scrolling sends coordinates with the correct direction. Captures carry monitor origins, including negative coordinates. Queued cancelled input is rejected; completed OS input keeps its real receipt. No accessible display returns a concrete error, not invented monitor dimensions.
- A compact desktop entry in the chat dock uses the same frozen context as the other workbench surfaces. Frame/input state is cleared on a device change, hidden panes stop polling, and Plan/Ask input remains disabled. Desktop audit records retain action/context, not typed keys or text.
